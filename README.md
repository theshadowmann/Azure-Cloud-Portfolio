# Azure Cloud Architecture Portfolio

## Overview
This repository showcases a collection of hands‑on Azure architecture projects designed to demonstrate real‑world cloud engineering skills. Each project includes a professionally designed architecture diagram and a detailed README explaining the purpose, services used, implementation steps, best practices, and interview‑ready talking points.

##  Projects Included
### **1. Governance & RBAC**  
Role‑based access control, policies, and resource locks for secure Azure governance.  
`/01-governance-and-rbac`

### **2️. Storage & SAS**  
Secure access to Blob, File, Queue, and Table storage using Shared Access Signatures.  
`/02-storage-and-sas`

### **3️. VMSS Autoscale**  
Virtual Machine Scale Sets with autoscaling rules, load balancing, and metrics‑driven scaling.  
`/03-vmss-autoscale`

### **4️. Two‑Tier VNet Architecture**  
Isolated frontend and backend subnets with NSGs and load balancing.  
`/04-two-tier-vnet`

### **5️. Monitor & KQL**  
Azure Monitor pipeline with metrics, logs, alerts, and KQL queries powering dashboards.  
`/05-monitor-and-kql`
